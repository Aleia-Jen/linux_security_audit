# Linux Security Audit Project

## Overview
This project documents a structured security audit of a simulated Ubuntu Linux system deployed within a virtualized environment. The audit evaluates access control, authentication policies, service exposure, logging configuration, and system hardening practices.

## Environment
- Host System: Apple Silicon (M4)
- Virtualization: Oracle VirtualBox
- Guest OS: Ubuntu ARM64
- Deployment Type: Simulated non-production environment

## Scope
The audit focuses on:
- User and privilege management
- Password and authentication policies
- Network service exposure
- Firewall configuration
- Logging and monitoring
- File system permissions

## Out of Scope
- Exploitation
- Active penetration testing
- External scanning
- Real-world infrastructure
